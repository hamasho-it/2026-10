# アプリ仕様書：ごみカツ！

## 1. アプリの名前と目的
- **アプリ名**：ごみカツ！
- **目的**：
  高齢化の進行によりゴミ出しが負担となっている一人暮らし高齢者（依頼者）と、地域でゴミ出しを手伝うボランティアをマッチングし、互助の地域コミュニティを形成するサポートアプリ。高齢者にはシンプルなUIや通知機能で負担を軽減し、ボランティアにはポイント還元制度で参加を促進・継続を支援する。

## 7. 守る条件
1. **技術構成**：HTML・CSS・JavaScriptのみ。外部DBおよびバックエンド・ログイン機能は構築しない。
2. **画面構成**：1画面＝1HTMLファイルとし、共通の `style.css` および `script.js` を `./style.css`・`./script.js` の相対パスで読み込む。
3. **リンク構造**：すべてのページ移動およびリソース参照は相対パス（`./`）を使用する。
4. **デザイン規約**：
   - 高齢者配慮のため、大きな文字サイズと押しやすい大きなボタン領域を確保する。
   - ワイヤーフレーム内のカッコ記号 `（ ）` は画面上に表示せず、中の文字列のみをボタンラベル等として使用する。
5. **画像管理**：`images` フォルダ配下に半角英数字で保存し、指定パスで呼び出す。未配置画像はグレーのダミー領域とする。

## 8. 確認したいこと（図にない・決まっていないこと）

1. **確定画面・対応不可時の戻り先挙動**
   - 依頼者側の「確定画面（対応できます画面）」で「確定する」を押した後の自動遷移先、およびボランティア側が「対応できません」を押した際のデータ消去の視覚的フィードバック（アニメーション等）の具体的演出。
2. **ボランティア側が「対応できます」を押したあとの依頼者側へのリアルタイム通知の再現**
   - データベースのないHTML/JS構成のため、ローカルストレージ（`localStorage`）等を利用してフラグを擬似的に切り替える仕組みの要否。
3. **家族に通知画面の役割と構成**
   - 依頼者本人用アプリ画面から「家族に通知」を開いた際、メッセージ履歴風の画面が表示されるが、ボタン「了解（家族）」を押す主体（家族端末か本人端末か）の仕様範囲。
